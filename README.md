# Calculadora en Python

## Descripción

Este proyecto consiste en una calculadora básica desarrollada en Python que permite realizar operaciones matemáticas simples entre dos números.

## Funciones

* Suma
* Resta
* Multiplicación
* División

## Requisitos

* Python 3 instalado en el equipo

## Cómo ejecutar el programa

1. Abrir una terminal o consola.
2. Ubicarse en la carpeta donde se encuentra el archivo `calculadora.py`.
3. Ejecutar el siguiente comando:

```bash
python calculadora.py
```

4. Ingresar los números y seleccionar la operación deseada.
